# Text-to-SQL Evaluation Framework

## Overview

This project demonstrates an end-to-end Text-to-SQL pipeline using SQLite and OpenAI.

## Pipeline

```text
Natural Language Question
        ↓
Schema Extraction
        ↓
Prompt Generation
        ↓
OpenAI API
        ↓
SQL Generation
        ↓
SQL Validation
        ↓
SQLite Execution
        ↓
Query Result
```

## Tech Stack

- Python
- SQLite
- OpenAI API
